Privacy Policy

Hermes Google Workspace · Last updated: October 21, 2026

Who uses this app

Hermes Google Workspace is a private integration used by a single person — its owner — to connect the owner's personal AI assistant to the owner's own Google account. It is not offered to, or used by, anyone else.

What data is accessed

With the owner's explicit consent, the app may access the following Google user data of the owner's account: Gmail messages and metadata, Google Calendar events, Google Drive files, Google Docs and Sheets content, and Google Contacts. Access is limited to the scopes the owner approved on the Google consent screen.

How data is used

Data is used only to perform tasks the owner requests or schedules — for example, summarizing new email, sending calendar reminders, or finding and editing documents. Results are delivered only to the owner's private chat.

How data is processed and stored

  • The assistant runs on a private server controlled by the owner. OAuth tokens are stored on that server and are never published.
  • To generate responses, relevant content may be sent to the AI model provider the assistant uses (currently OpenAI) for processing.
  • Google user data is not sold, not used for advertising, and not shared with any other third party.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Revoking access stops all further data retrieval.
